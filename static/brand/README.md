# static/brand

Generated by `npm run brand` (`scripts/brand.mjs`) from `league/league.json`. Do not edit these
files: change `theme`, `name` or `founded` in league.json, or put a hand-made replacement with
the same file name in `league/brand/`, and run `npm run brand` again.

| File | Used for |
| --- | --- |
| `seal.svg` | the full mark, 96px and up |
| `seal-simple.svg` | the nav logo, the favicon, and the source of every raster icon |
| `wordmark.svg` | the horizontal lockup (README, wide headers) |
| `banner.svg` | the champion's ribbon; it carries no text, the heading is real markup |
| `laurel.svg` | the wreath around the reigning champion |

The templates are in `scripts/brand-templates/`. An SVG shown through `<img>` gets no page CSS and
no webfonts, so colours are written in as literal hex and text widths are pinned with
`textLength`. Some rasterizers (librsvg, so sharp) do not draw `textPath`; browsers do, and only
the text-free `seal-simple.svg` is rasterized for icons, and `seal.svg` with `wordmark.svg` for
the iOS launch screens.
