# AGENTS.md

Instructions for coding agents live in [CLAUDE.md](CLAUDE.md) (the engine) and
[league/NOTES.md](league/NOTES.md) (this league's facts). The step-by-step playbooks are the
skills in [.claude/skills/](.claude/skills/): `league-setup` builds a site for a Sleeper league,
`league-data` produces verified numbers, `league-recap` and `league-preview` write the blog, and
`league-season` handles the season rollover. Each is a plain Markdown file any agent can follow.
